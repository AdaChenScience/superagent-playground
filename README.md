# 用 Super-agent 跟踪 Marin

Marin 的训练进展分散在持续更新的 Issue 和 PR 中。我需要定期做宣传教学视频，也想借它理解大模型从零训练的过程，但没有精力追完所有工程讨论。

目标是让 Agent 找出值得关注的变化，解释它影响训练的哪一环，保留证据和待观察事项；我只在选题取舍和发布时做判断。

## 为什么尝试 Super-agent

一次资料总结用 Codex 就能完成。这里要验证的是后续更新：新消息能否回到已有任务，执行会话能否接着工作，研究与核查能否分开，再通过 PR 检查修改。

本次跑通了 Issue 请求、原任务续接、执行 Agent 委派 DSH 子 Agent、核查返工和 PR 交付。Super-agent 管任务生命周期；执行模型决定具体研究和分工；DSH 提供会话与工具。子 Agent 数量本身不代表效果。

## 跑出什么，离目标还差什么

首轮在固定时间窗口内筛出三个候选选题，保留来源、暂缓项和下次观察点。一次有用的核查是：把“没有长上下文评测”修正为区分常规预测误差评测与专门的长文能力测试，避免讲错结论。

但这仍是一次研究快照。后续评论验证了任务续接，没有验证 Marin 新进展的周期抓取、跨期去重和重要性筛选。教学稿经过多轮修改，使用者仍不满意。当前能证明工作流跑通，尚不能证明已经稳定减轻跟踪负担。

- [下一轮任务与验收](docs/task-contract.md)：用一次增量跟踪验证是否真的有用。
- [运行证据与历史产物](docs/evidence-index.md)：请求、反馈、PR、状态快照和原始交付。

这是开源框架的使用与评估实践。用户提出需求并判断效果；Codex 协助部署、派发、验收和文档整理；Super-agent 与 DSH 上的模型执行研究。不是自研框架。研究材料截至 2026-11-02 05:30 UTC，不能当作实时进展。
