## 必须避免的推断

- “前文越多，答案越可预测”过度概括；关键在“多出来的部分是否含有关键信息，模型能否找到并用上”。
- “检查通过 = 完全安全”；只覆盖 103 步和一次切换。
- “loss 更低 = 所有任务能力更强”；loss 是下一 token 预测误差，不是长文能力评测。
- “能输入 65K = 能有效利用 65K 里的信息”；容量≠有效使用。
- “下一次常规 65K 评测（loss/Paloma）= 专门长文能力测试”；常规评测补预测误差，不等于“能否找到并用上长文关键信息”的能力结论。
- “合并代码 = 能力突破”；工程动作不是能力结果。
- “第一次评测在 17:20Z”必须写“预计”；截点前没有结果。
